# Prototype

## 목표

기존 객체를 복사해 비슷한 설정의 새 객체를 만듭니다.

## 만들어 볼 기능

아래 예시 중 하나를 선택하거나 같은 목표를 연습할 수 있는 기능을 직접 정합니다.

1. **문서 작성**: 여러 문단과 표, 서식이 설정된 문서를 양식으로 보관합니다. 양식을 복사해 새 문서를 만들고 표를 수정해도 양식은 유지합니다.
2. **게임 캐릭터 생성**: 능력치와 장비 목록이 담긴 기본 캐릭터를 복사하고, 복사본의 장비를 바꿔도 원본은 유지합니다.

## 실습 조건

복사본의 값을 바꿨을 때 원본이 의도치 않게 바뀌지 않는지 확인하세요. 중첩된 가변 데이터를 하나 이상 포함하세요.

## 생각해 볼 질문

얕은 복사와 깊은 복사는 언제 다른 결과를 만드나요? 복사보다 새로 생성하는 편이 나은 경우는 언제인가요?

## 완료 기준

선택한 기능의 동작을 테스트 또는 실행 결과로 확인하고, 패턴을 적용한 이유와 더 단순한 대안의 장단점을 자신의 말로 정리합니다.
