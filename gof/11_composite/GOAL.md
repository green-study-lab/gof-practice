# Composite

## 목표

단일 객체와 그 객체들을 담는 묶음을 공통 방식으로 다룹니다.

## 만들어 볼 기능

아래 예시 중 하나를 선택하거나 같은 목표를 연습할 수 있는 기능을 직접 정합니다.

1. **파일 탐색기**: 파일과 하위 폴더를 중첩해 구성하고, 최상위 폴더에서 전체 파일 크기를 계산합니다.
2. **쇼핑 장바구니**: 단일 상품과 상품 묶음을 장바구니에 담고, 중첩된 묶음까지 포함해 총금액을 계산합니다.

## 실습 조건

단일 항목과 묶음에 공통 연산을 제공하고, 두 단계 이상 중첩된 구조에서 결과를 확인하세요.

## 생각해 볼 질문

단일 항목에 자식 추가 기능이 필요한가요? 공통 인터페이스의 단순함과 잘못된 연산을 막는 것 사이에 어떤 선택이 있나요?

## 완료 기준

선택한 기능의 동작을 테스트 또는 실행 결과로 확인하고, 패턴을 적용한 이유와 더 단순한 대안의 장단점을 자신의 말로 정리합니다.
