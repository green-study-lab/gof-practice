# Interpreter

## 목표

작은 표현식의 문법을 정의하고 해석합니다.

## 만들어 볼 기능

아래 예시 중 하나를 선택하거나 같은 목표를 연습할 수 있는 기능을 직접 정합니다.

1. **상품 검색**: `재고 있음 AND 할인 중` 조건을 구성해 상품 목록에 적용하고, 두 조건을 모두 만족하는 상품을 출력합니다.
2. **알림 규칙**: `온도 높음 OR 습도 높음` 조건을 구성해 측정값에 적용하고, 조건을 만족하면 알림을 출력합니다.
3. **가계부 거래 분류**: `거래처가 카페 AND 금액이 1만 원 미만`인 거래를 찾아 식비로 분류합니다. 조건을 바꿔 다른 거래에도 적용합니다.

## 실습 조건

조건과 논리 연산을 표현하는 구조를 만들고 중첩된 표현식을 평가하세요. 문자열 파싱은 선택 사항이며 객체를 직접 조합해도 됩니다.

## 생각해 볼 질문

표현식이 커지면 이 구조가 이해하기 어려워지는 이유는 무엇인가요? 파서와 표현식 평가의 책임은 어떻게 다른가요?

## 완료 기준

선택한 기능의 동작을 테스트 또는 실행 결과로 확인하고, 패턴을 적용한 이유와 더 단순한 대안의 장단점을 자신의 말로 정리합니다.
