# Flyweight

## 목표

여러 객체에서 반복되는 공통 상태를 공유하고 개별 상태와 분리합니다.

## 만들어 볼 기능

아래 예시 중 하나를 선택하거나 같은 목표를 연습할 수 있는 기능을 직접 정합니다.

1. **지도 표시**: 같은 종류의 마커 여러 개가 아이콘과 색상을 공유하고, 각 마커의 위치와 이름은 따로 관리합니다.
2. **문서 편집기**: 여러 글자가 같은 글꼴 설정을 공유하고, 각 글자의 문자와 위치는 따로 관리합니다.

## 실습 조건

공유 가능한 상태와 항목별 상태를 구분하고, 같은 공통 상태가 재사용되는지 확인하세요. 필요하다면 메모리 차이를 측정하되 환경을 함께 기록하세요.

## 생각해 볼 질문

공유 객체가 변경 가능하면 어떤 문제가 생길까요? 객체 수가 적을 때도 이 구조가 이득일까요?

## 완료 기준

선택한 기능의 동작을 테스트 또는 실행 결과로 확인하고, 패턴을 적용한 이유와 더 단순한 대안의 장단점을 자신의 말로 정리합니다.
