# Factory Method

## 목표

객체를 사용하는 공통 흐름과 구체적인 객체의 생성 방식을 분리합니다.

## 만들어 볼 기능

아래 예시 중 하나를 선택하거나 같은 목표를 연습할 수 있는 기능을 직접 정합니다.

1. **문서 내보내기**: 내보내기 작업을 시작하면 선택한 방식의 작성기를 생성하고, 문서를 텍스트 또는 HTML로 출력합니다.
2. **파일 가져오기**: 가져오기 작업을 시작하면 CSV 또는 JSON 읽기 객체를 생성하고, 공통 절차로 데이터를 읽어 결과를 표시합니다.

## 실습 조건

공통 흐름 안에서 생성 메서드를 호출하고, 하위 구현 두 가지가 서로 다른 객체를 만들도록 하세요. 단순한 조건문을 둔 생성 함수와도 비교해 보세요.

## 생각해 볼 질문

생성자를 직접 호출하는 경우와 무엇이 달라지나요? 생성만 바꾸기 위해 상속하는 비용은 무엇인가요?

## 완료 기준

선택한 기능의 동작을 테스트 또는 실행 결과로 확인하고, 패턴을 적용한 이유와 더 단순한 대안의 장단점을 자신의 말로 정리합니다.
