# Visitor

## 목표

객체 구조와 그 구조에 적용하는 연산을 분리합니다.

## 만들어 볼 기능

아래 예시 중 하나를 선택하거나 같은 목표를 연습할 수 있는 기능을 직접 정합니다.

1. **도형 편집기**: 원과 사각형이 섞인 목록에 면적 계산과 화면 출력 연산을 차례로 적용합니다.
2. **문서 검사**: 문단과 이미지로 이루어진 문서에 텍스트 추출과 접근성 검사 연산을 각각 적용합니다. 문서 요소 종류를 유지한 채 새 검사 연산을 추가해 봅니다.

## 실습 조건

요소 종류 두 가지와 연산 두 가지를 만들고, 각 연산이 요소 종류에 맞게 처리되는지 확인하세요.

## 생각해 볼 질문

새 연산을 추가할 때와 새 요소 종류를 추가할 때 각각 어떤 코드가 바뀌나요? 조건문이나 언어의 패턴 매칭과 비교하면 어떤가요?

## 완료 기준

선택한 기능의 동작을 테스트 또는 실행 결과로 확인하고, 패턴을 적용한 이유와 더 단순한 대안의 장단점을 자신의 말로 정리합니다.
