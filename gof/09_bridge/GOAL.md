# Bridge

## 목표

독립적으로 변하는 두 차원을 분리해 조합할 수 있도록 구성합니다.

## 만들어 볼 기능

아래 예시 중 하나를 선택하거나 같은 목표를 연습할 수 있는 기능을 직접 정합니다.

1. **알림 발송**: 주문 완료 또는 결제 실패 알림을 만들고, 이메일 또는 문자 중 선택한 방식으로 전달합니다.
2. **원격 제어**: 기본 리모컨 또는 예약 리모컨으로 TV나 오디오를 조작합니다. 리모컨 종류와 기기 종류를 독립적으로 교체합니다.

## 실습 조건

두 차원에서 각각 두 가지 변형을 만들고, 조합을 바꿔도 동작하도록 구현하세요.

## 생각해 볼 질문

모든 조합을 상속으로 만드는 방식과 비교하면 클래스 수와 변경 범위가 어떻게 달라지나요?

## 완료 기준

선택한 기능의 동작을 테스트 또는 실행 결과로 확인하고, 패턴을 적용한 이유와 더 단순한 대안의 장단점을 자신의 말로 정리합니다.
