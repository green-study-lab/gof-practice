# State

## 목표

객체의 현재 상태에 따라 같은 요청의 동작이 달라지도록 합니다.

## 만들어 볼 기능

아래 예시 중 하나를 선택하거나 같은 목표를 연습할 수 있는 기능을 직접 정합니다.

1. **주문 처리**: 주문은 결제 대기, 결제 완료, 배송 중 상태를 가집니다. 취소 요청 시 결제 대기는 즉시 취소하고 결제 완료는 환불하며 배송 중은 거절합니다.
2. **음악 재생기**: 정지 상태에서 재생을 시작하고 일시 정지한 뒤 재개합니다. 상태별로 같은 버튼의 동작을 확인합니다.

## 실습 조건

상태 세 가지 이상과 허용되는 전이를 정의하고, 허용되지 않는 요청의 결과도 테스트하세요.

## 생각해 볼 질문

상태별 클래스를 쓰는 것과 열거형 및 조건문을 쓰는 것의 장단점은 무엇인가요? 상태 전이 규칙은 어디에 두는 게 명확한가요?

## 완료 기준

선택한 기능의 동작을 테스트 또는 실행 결과로 확인하고, 패턴을 적용한 이유와 더 단순한 대안의 장단점을 자신의 말로 정리합니다.
