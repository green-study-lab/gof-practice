# Abstract Factory

## 목표

함께 사용해야 하는 관련 객체들을 구체적인 클래스에 의존하지 않고 생성합니다.

## 만들어 볼 기능

아래 예시 중 하나를 선택하거나 같은 목표를 연습할 수 있는 기능을 직접 정합니다.

1. **게임 맵 생성**: 사막 또는 설원 지역을 선택하면 해당 지역에 어울리는 지형과 적을 함께 만들어 맵을 준비합니다.
2. **문서 출력**: HTML 또는 PDF 내보내기를 선택하면 해당 형식의 본문 작성기와 이미지 처리기를 함께 생성해 문서를 출력합니다.

## 실습 조건

서로 다른 두 종류의 제품을 만드는 팩토리와 제품군 두 가지를 구현하세요. 각 팩토리가 만든 제품들이 같은 계열인지 확인하세요.

## 생각해 볼 질문

Factory Method와 비교할 때 관련 제품들을 묶어 생성하는 이점은 무엇인가요? 제품 종류를 추가하면 어떤 부분이 바뀌나요?

## 완료 기준

선택한 기능의 동작을 테스트 또는 실행 결과로 확인하고, 패턴을 적용한 이유와 더 단순한 대안의 장단점을 자신의 말로 정리합니다.
