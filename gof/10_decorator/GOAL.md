# Decorator

## 목표

기존 객체를 감싸 기능을 유연하게 덧붙입니다.

## 만들어 볼 기능

아래 예시 중 하나를 선택하거나 같은 목표를 연습할 수 있는 기능을 직접 정합니다.

1. **파일 내보내기**: 기본 파일 쓰기에 압축과 암호화 기능을 선택적으로 덧붙입니다. 적용 순서를 바꾸고 결과가 어떻게 달라지는지 확인합니다.
2. **메시지 출력**: 기본 메시지에 시간 표시와 강조 표시를 덧붙이고, 적용 순서에 따른 결과를 확인합니다.

## 실습 조건

공통 인터페이스를 가진 기본 구현과 장식 두 가지를 만들고, 장식의 조합과 순서에 따른 결과를 확인하세요. 암호화 예시는 실제 보안을 위한 구현이 아니라 동작 실험으로 다뤄도 됩니다.

## 생각해 볼 질문

장식을 적용하는 순서가 결과에 영향을 줄까요? 상속으로 조합을 만드는 방식과 비교하면 무엇이 달라지나요?

## 완료 기준

선택한 기능의 동작을 테스트 또는 실행 결과로 확인하고, 패턴을 적용한 이유와 더 단순한 대안의 장단점을 자신의 말로 정리합니다.
