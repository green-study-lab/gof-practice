# Proxy

## 목표

대상 객체 앞에 대리 객체를 두어 접근을 제어하거나 추가 동작을 수행합니다.

## 만들어 볼 기능

아래 예시 중 하나를 선택하거나 같은 목표를 연습할 수 있는 기능을 직접 정합니다.

1. **비공개 문서 조회**: 사용자가 문서 조회를 요청하면 권한을 확인하고, 허용된 경우에만 내용을 반환합니다.
2. **사진 앨범**: 목록에서는 작은 미리보기로 사진을 보여주고, 사용자가 한 장을 열 때만 큰 이미지를 불러옵니다. 불러오는 과정을 횟수로 기록해 지연 시점을 확인합니다.

## 실습 조건

대상과 대리 객체에 같은 인터페이스를 제공하고, 직접 접근과 대리 접근의 차이를 테스트하세요. 권한이나 지연 로딩 중 하나를 선택하세요.

## 생각해 볼 질문

Decorator와 Proxy는 구조가 비슷한데 의도는 어떻게 다른가요? 대리 객체가 실패나 지연을 숨겨도 될까요?

## 완료 기준

선택한 기능의 동작을 테스트 또는 실행 결과로 확인하고, 패턴을 적용한 이유와 더 단순한 대안의 장단점을 자신의 말로 정리합니다.
