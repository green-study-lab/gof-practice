# Builder

## 목표

선택 가능한 설정이 많은 객체의 생성 과정을 단계적으로 구성합니다.

## 만들어 볼 기능

아래 예시 중 하나를 선택하거나 같은 목표를 연습할 수 있는 기능을 직접 정합니다.

1. **리포트 생성**: 기간을 정하고 필터, 포함할 항목, 정렬 기준을 단계적으로 추가한 뒤, 완성된 설정으로 보고서를 만듭니다.
2. **HTTP 요청 만들기**: 주소와 메서드를 지정하고 헤더, 본문, 타임아웃을 선택적으로 추가해 요청을 구성합니다.
3. **가계부 가져오기 설정**: CSV의 날짜·금액 열을 지정하고 날짜 형식이나 금액 부호 반전을 선택한 뒤, 완성된 설정으로 거래 내역을 읽습니다. 같은 디렉터리의 `transactions.csv`를 사용할 수 있습니다.

## 실습 조건

필수 항목과 선택 항목을 정하고, 서로 다른 설정 두 가지를 생성하세요. 잘못된 설정은 생성 시점에 확인하세요.

## 생각해 볼 질문

생성자나 언어의 기본 인자와 비교할 때 Builder가 유용한 조건은 무엇인가요? 생성 후 설정을 바꿀 수 있어야 하나요?

## 완료 기준

선택한 기능의 동작을 테스트 또는 실행 결과로 확인하고, 패턴을 적용한 이유와 더 단순한 대안의 장단점을 자신의 말로 정리합니다.
