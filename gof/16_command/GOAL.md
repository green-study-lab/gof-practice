# Command

## 목표

요청을 객체로 표현해 실행이나 취소를 다룹니다.

## 만들어 볼 기능

아래 예시 중 하나를 선택하거나 같은 목표를 연습할 수 있는 기능을 직접 정합니다.

1. **텍스트 편집기**: 문장을 추가하거나 삭제하는 명령을 실행하고 마지막 편집을 취소해 이전 내용을 표시합니다.
2. **스마트 조명**: 조명 켜기와 밝기 변경을 명령으로 실행하고, 마지막 밝기 변경을 취소합니다.
3. **외출 준비 버튼**: 버튼을 누르면 조명 끄기와 알림 보내기를 순서대로 실행합니다. 실행한 명령을 기록하고 조명 끄기는 취소할 수 있게 합니다.

## 실습 조건

명령 두 가지의 실행을 구현하고, 적어도 하나는 취소할 수 있게 하세요. 실행 전후와 취소 후 상태를 확인하세요.

## 생각해 볼 질문

취소에 필요한 이전 상태는 누가 보관하나요? 단순 함수 호출과 비교할 때 명령 객체가 유용한 상황은 언제인가요?

## 완료 기준

선택한 기능의 동작을 테스트 또는 실행 결과로 확인하고, 패턴을 적용한 이유와 더 단순한 대안의 장단점을 자신의 말로 정리합니다.
