# Memento

## 목표

객체의 내부 상태를 외부에 노출하지 않고 저장했다가 복원합니다.

## 만들어 볼 기능

아래 예시 중 하나를 선택하거나 같은 목표를 연습할 수 있는 기능을 직접 정합니다.

1. **그림 편집기**: 도형을 추가할 때마다 그림 상태를 저장하고, 원하는 저장 시점의 그림으로 복원합니다.
2. **게임 저장**: 플레이어의 위치와 보유 아이템을 저장하고, 이후 변경된 상태를 이전 저장 지점으로 되돌립니다.
3. **메모 버전 복원**: 메모의 제목과 내용을 수정하면서 이전 버전을 보관하고, 원하는 버전을 선택해 복원합니다.

## 실습 조건

상태를 두 번 이상 저장하고 원하는 시점으로 복원하세요. 저장 후 원본을 변경해도 저장된 상태가 바뀌지 않는지 확인하세요.

## 생각해 볼 질문

상태를 깊게 복사해야 하는 경우는 언제인가요? 저장 이력의 개수와 메모리 사용량은 어떻게 제한할까요?

## 완료 기준

선택한 기능의 동작을 테스트 또는 실행 결과로 확인하고, 패턴을 적용한 이유와 더 단순한 대안의 장단점을 자신의 말로 정리합니다.
