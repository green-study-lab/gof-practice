# Mediator

## 목표

여러 객체 사이의 상호작용을 중재 객체에 모읍니다.

## 만들어 볼 기능

아래 예시 중 하나를 선택하거나 같은 목표를 연습할 수 있는 기능을 직접 정합니다.

1. **예약 화면**: 날짜와 인원을 선택하면 중재자가 가능한 시간 목록을 갱신하고, 유효한 시간이 선택된 경우에만 예약 버튼을 활성화합니다.
2. **항공 관제**: 비행기가 이착륙을 요청하면 관제소가 활주로 사용 여부를 확인하고 허가 또는 대기를 전달합니다.

## 실습 조건

참여 객체 세 개 이상과 중재자를 만들고, 참여 객체들이 서로를 직접 호출하지 않도록 연결하세요.

## 생각해 볼 질문

중재자가 지나치게 많은 책임을 갖게 되는 시점은 언제인가요? Observer와 비교해 누가 상호작용 규칙을 아나요?

## 완료 기준

선택한 기능의 동작을 테스트 또는 실행 결과로 확인하고, 패턴을 적용한 이유와 더 단순한 대안의 장단점을 자신의 말로 정리합니다.
