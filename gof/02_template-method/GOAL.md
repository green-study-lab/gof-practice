# Template Method

## 목표

전체 실행 순서를 정의하고 일부 단계를 서로 다르게 구현합니다.

## 만들어 볼 기능

아래 예시 중 하나를 선택하거나 같은 목표를 연습할 수 있는 기능을 직접 정합니다.

1. **음료 만들기**: 물 준비, 재료 넣기, 완성 순서를 유지하면서 차와 커피의 재료와 추출 단계를 다르게 처리합니다.
2. **데이터 내보내기**: 데이터를 조회하고 형식을 변환한 뒤 저장합니다. CSV와 JSON은 변환 단계를 다르게 구현합니다.
3. **게임 라운드**: 참가자를 준비하고 라운드를 진행한 뒤 결과를 출력합니다. 일반 라운드와 보너스 라운드는 점수 계산을 다르게 처리합니다.

## 실습 조건

공통 흐름을 정의하고 바뀌는 단계를 두 가지 이상 구현하세요. 실행 순서와 각 구현의 결과를 확인하세요.

## 생각해 볼 질문

어떤 단계는 재정의할 수 없도록 제한해야 하나요? 상속 대신 함수나 객체를 전달하면 무엇이 달라지나요?

## 완료 기준

선택한 기능의 동작을 테스트 또는 실행 결과로 확인하고, 패턴을 적용한 이유와 더 단순한 대안의 장단점을 자신의 말로 정리합니다.
