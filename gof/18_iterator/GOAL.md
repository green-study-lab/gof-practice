# Iterator

## 목표

컬렉션의 내부 구조를 노출하지 않고 항목을 순회합니다.

## 만들어 볼 기능

아래 예시 중 하나를 선택하거나 같은 목표를 연습할 수 있는 기능을 직접 정합니다.

1. **페이지별 상품 조회**: 상품을 페이지 단위로 받아 오되, 호출자는 페이지 경계를 몰라도 순회자로 상품을 하나씩 읽습니다.
2. **도서 목록**: 대출 여부가 섞인 도서 목록을 순회자로 읽고, 대출 가능한 책만 차례대로 출력합니다.

## 실습 조건

순회할 데이터와 순회자를 만들고 항목에 접근하세요. 빈 결과와 순회 중 데이터 변경을 어떻게 처리할지도 정해 확인하세요. 페이지 조회 예시는 외부 서비스 없이 페이지별 데이터를 준비해도 됩니다.

## 생각해 볼 질문

언어가 제공하는 반복자나 컬렉션 필터와 비교할 때 직접 구현이 유용한 경우는 언제인가요?

## 완료 기준

선택한 기능의 동작을 테스트 또는 실행 결과로 확인하고, 패턴을 적용한 이유와 더 단순한 대안의 장단점을 자신의 말로 정리합니다.
