# Facade

## 목표

여러 구성 요소가 필요한 작업에 간단한 진입점을 제공합니다.

## 만들어 볼 기능

아래 예시 중 하나를 선택하거나 같은 목표를 연습할 수 있는 기능을 직접 정합니다.

1. **영화 예매**: 영화와 좌석을 선택하면 좌석 확인, 결제, 예약 생성 과정을 거쳐 예매 결과를 반환합니다.
2. **파일 업로드**: 파일을 전달하면 형식과 크기를 확인하고 저장한 뒤 접근 주소를 반환합니다.
3. **영수증 정리**: 영수증 파일을 제출하면 글자를 추출하고 문서에 태그를 붙인 뒤 저장합니다. 글자 추출은 실제 OCR 대신 미리 준비한 결과를 사용해도 됩니다.

## 실습 조건

각 단계를 별도 구성 요소로 만들고, 호출자가 하나의 진입점으로 전체 작업을 실행하도록 하세요. 중간 단계가 실패하는 경우도 확인하세요.

## 생각해 볼 질문

Facade에 어디까지 책임을 둘까요? 단순히 호출만 감싼 클래스와 의미 있는 진입점은 어떻게 다를까요?

## 완료 기준

선택한 기능의 동작을 테스트 또는 실행 결과로 확인하고, 패턴을 적용한 이유와 더 단순한 대안의 장단점을 자신의 말로 정리합니다.
